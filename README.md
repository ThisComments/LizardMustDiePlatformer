# РУСЫ ПРОТИВ ЯЩЕРОВ

2D pixel-art action platformer на C++ и SFML 3.

Игроку предстоит вернуть украденное измерение Руси, сражаясь с ящерами, преодолевая препятствия и исследуя мир, в котором славянская архитектура сталкивается с технологиями древней рептильной цивилизации.

## О проекте

**РУСЫ ПРОТИВ ЯЩЕРОВ** — платформер с упором на динамичное перемещение, боевую систему и взаимодействие с окружением.

Проект разрабатывается с расчётом на дальнейшее расширение: новые типы противников, механики перемещения, поверхности, жидкости, интерактивные объекты, уровни и игровые системы должны добавляться без необходимости переписывать существующую архитектуру.

## Архитектура

Проект разделён на отдельные игровые системы с разграничением ответственности.

Основные модули:

* `Game` — основной игровой цикл и управление состоянием игры
* `World` — игровое окружение и игровые сущности
* `Player` — состояние и поведение игрока
* `PlayerInput` — описание пользовательского ввода
* `KeyboardHandler` — получение ввода с клавиатуры
* `CollisionSystem` — обнаружение и обработка столкновений

Архитектура предусматривает дальнейшее развитие игровых систем без жёсткой зависимости между отдельными компонентами.

## Сборка и запуск

### Требования

* Компилятор с поддержкой C++17
* CMake версии 3.26 или новее
* SFML  (Graphics, Audio) версии 3.0 или новее
* toml++ версии 3.4 или новее
* TagLib версии 2.2 или новее

### Сборка

```bash
git clone <repository-url>
cd <project-directory>

cmake -S . -B build
cmake --build build
```

### Запуск

```bash
./build/game
```

При каждой сборке каталоги `assets/`, `settings/` и `levels/` копируются рядом с исполняемым файлом.

Игра использует каталог исполняемого файла как корневой каталог ресурсов. Поэтому запускать её необходимо по пути к исполняемому файлу, а не через поиск команды в `PATH`.

Все пути к ресурсам в коде и toml-конфигурациях задаются относительно корневого каталога игры.

## Конфигурация и данные

Часть игровых систем использует внешние toml-файлы. Это позволяет изменять параметры и добавлять контент без необходимости изменять исходный код.

### Анимации

Для каждого спрайт-листа используется отдельный toml-файл с тем же именем, что и текстура.

Например:

```text
hero.png
hero.toml
```

Конфигурации содержат следующие параметры:

* `frame_size` — размер одного кадра
* `columns` — количество столбцов в спрайт-листе
* `origin` — относительная точка привязки спрайта
* `draw_scale` — масштаб отображения (необязательный)
* `animations` — список анимаций с параметрами:
  * `first_frame` — индекс первого кадра
  * `frame_count` — количество кадров
  * `fps` — частота смены кадров
  * `loop` — зацикливание анимации

При загрузке конфигурация проверяется на корректность и соответствие размерам текстуры. При обнаружении ошибок указываются файл и проблемное поле.

### Аудиосистема

Основная конфигурация аудио находится в `settings/audio.toml`.

Она содержит:

* `volume` — громкость отдельных категорий:
  * `master` — общая громкость
  * `music` — громкость музыки
  * `effects` — громкость звуковых эффектов

  Значения задаются в диапазоне от 0 до 100.

* `music` — настройки музыкального сопровождения:
  * `repea_pPlaylist` — повторение плейлиста
  * `shuffle` — случайный порядок воспроизведения
  * `playlist` — список музыкальных композиций с идентификаторами `id` и путями `file`

* `sounds` — настройки звуковых эффектов:
  * `file` — путь к аудиофайлу
  * `volume` — индивидуальная громкость
  * `voices` — максимальное количество одновременно воспроизводимых экземпляров звука

Добавление нового звукового эффекта требует создания новой записи в конфигурации и вызова:

```cpp
AudioManager::PlaySfx("name");
```

Для добавления музыкальной композиции достаточно добавить новую запись в плейлист.

Названия композиций и исполнители считываются из метаданных аудиофайлов. Если метаданные отсутствуют, используется имя файла.

## Визуальный стиль

Игра использует яркий pixel-art стиль с элементами славянского фэнтези.

Основные направления мира:

* **Русь / Гиперборея** — ледяные города, деревянная архитектура, купола, руны и тёплое освещение.
* **Атлантида** — бирюзовые и золотые храмы, технологии ящеров.
* **Захваченный дирижабль** — сочетание славянской деревянной конструкции и технологий рептильной цивилизации.

Визуальный стиль ориентирован на читаемость игровых объектов и контраст с более мрачными action-платформерами.
