# РУСЫ ПРОТИВ ЯЩЕРОВ

2D pixel-art action platformer на C++ и SFML.

Игроку предстоит вернуть украденное измерение Руси, сражаясь с ящерами, преодолевая препятствия и исследуя мир, в котором славянская архитектура сталкивается с технологиями древней рептильной цивилизации.

## О проекте

**РУСЫ ПРОТИВ ЯЩЕРОВ** — платформер с упором на динамичное перемещение, боевую систему и взаимодействие с окружением.

Проект разрабатывается с расчётом на дальнейшее расширение: новые типы противников, механики перемещения, поверхности, жидкости, интерактивные объекты, уровни и игровые системы должны добавляться без необходимости переписывать существующую архитектуру.

## Архитектура

Проект разделён на отдельные игровые системы.

Основные модули:

* `Game` — основной игровой цикл и управление состоянием игры
* `World` — игровое окружение и игровые сущности
* `Player` — состояние и поведение игрока
* `PlayerInput` — описание пользовательского ввода
* `KeyboardHandler` — получение ввода с клавиатуры
* `CollisionSystem` — обнаружение и обработка столкновений
* `Obstacle` — объекты окружения

Архитектура рассчитана на дальнейшее разделение игровых систем по мере роста проекта.

## Визуальный стиль

Игра использует яркий pixel-art стиль с элементами славянского фэнтези.

Основные направления мира:

* **Русь / Гиперборея** — ледяные города, деревянная архитектура, купола, руны и тёплое освещение
* **Атлантида** — бирюзовые и золотые храмы, технологии ящеров
* **Захваченный дирижабль** — сочетание славянской деревянной конструкции и технологий рептильной цивилизации

Визуальный стиль ориентирован на читаемость игровых объектов и контраст с более мрачными action-платформерами.
